# Native Crash 监控开发计划

## 项目概述

基于 OpenHarmony 平台的 APM SDK Native Crash 监控功能开发，采用 Crash Delayer + HiAppEvent 系统协同方案。

## 风险与依赖

| 风险项 | 影响 | 应对措施 |
|--------|------|---------|
| HiAppEvent 系统回调延迟 | 可能超过 3 秒超时 | 调整超时时间为 5 秒，增加日志监控 |
| faultloggerd 日志生成失败 | 崩溃信息丢失 | 增加降级方案，记录基础崩溃信号信息 |
| TaskPool 线程卡住 | 监控服务失效 | 增加心跳检测，异常时重启监控线程 |
| 跨版本兼容性 | 不同 OpenHarmony 版本行为差异 | 适配多版本，增加版本检测逻辑 |
